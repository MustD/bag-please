Direction 3 — Edge-to-Edge

Direction 4 — Inline Tabs

Login and Register live on the same card, switching via tabs. Reduces navigation between pages. Best if registration is usually open; awkward when registration is disabled (tab hidden).

  • Slightly more complex — tab state management in the component
